OpenTSx SaaS backend

This service is the API of the OpenTSx web application. It keeps accounts, stored flows and the working copies of signal bindings, and it forwards DAG deployments and demo generators to the retrieval server. Every route under /api/v1 except register, login, mode and openapi.json needs the access token of POST /api/v1/auth/login.

  • /docs: the routes (OpenAPI, Swagger UI), where you can sign in and try them
  • /api/v1/openapi.json: the OpenAPI document
  • /health: answers when the backend runs
  • /ready: answers 200 when the database answers
  • http://localhost:3000: the web application, where docker-compose.yml publishes it
