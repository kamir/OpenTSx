# Code of Conduct

OpenTSx adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to all project spaces (issues, pull requests, discussions, reviews) and to anyone
representing the project in public.

In short: be respectful and constructive, welcome people with different backgrounds and levels of experience, accept
criticism of your work gracefully, and focus on what is best for the project and its users. Harassment, insults,
personal or political attacks, and publishing other people's private information are not acceptable.

## Reporting

Report unacceptable behavior to the repository owner ([@kamir](https://github.com/kamir)):

* open a GitHub issue that asks for a private contact, without the details of the incident, or
* for incidents that must not be visible at all, use GitHub's private vulnerability reporting
  (see [SECURITY.md](SECURITY.md)) and state that the report is a code-of-conduct matter.

All reports are reviewed and handled confidentially. The maintainers act according to the enforcement guidelines of
the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).
