# Archived documentation (2025 and older)

These documents describe the 2.x platform (Java 8/11, Confluent Platform/Cloud, ksqlDB, Cassandra, Hadoop). They are
kept for reference only. **They are not maintained, and many code examples in them do not match the current code.**
The current documentation is the [user manual](../../docs/user-manual/README.md).

| Folder/file | What it was |
|-------------|-------------|
| `manual-v1/` | GitBook "Core Manual" around `TimeSeriesObject` (many TOC links were never written) |
| `onboarding-2025/` | four onboarding tracks (SWE, TSx, Python, Flink) with reviews |
| `devguide-2025/` | architecture, module, feature, deployment and security guides, FAQ, troubleshooting |
| `MANUALS-2025/` | learning-path "journeys" (physicist, developer, beginner) and feature proposals |
| `00_MATERIAL/` | conference slides, sketches (OmniGraffle), drafts, marketing |
| `README-2025.md` | the previous root README |
| `SUMMARY-2025.md`, `PDF-GENERATION-root-copy.md`, `NEXT_STEPS_PDF_GENERATION.md` | old index and tooling notes |

The material still worth having was carried into the new manual:

* algorithm theory (DFA, MFDFA, event synchronization, return-interval statistics),
* the 2.x API overview,
* the publication list.

`devguide-2025/guides/SECURITY.md` contained a Confluent Cloud key; it is redacted in this copy, but remains in the git history.
